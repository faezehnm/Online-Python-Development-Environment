📚 راهنمای کدهای نمونه پایتون و ترتل

ویژه مدرسین کلاس کدنوردی - دبیرستان مفید
۱. رسم مربع رنگی با ترتل (Turtle Square) 
import turtle

turtle.bgcolor("#1e1e2f")
turtle.color("cyan", "pink")
turtle.width(3)

turtle.penup()
turtle.goto(-50, 50)
turtle.pendown()

turtle.begin_fill()
for i in range(4):
    turtle.forward(100)
    turtle.right(90)
turtle.end_fill()

print("مربع رنگی رسم شد! ✨")
۲. رسم دایره با ترتل (Turtle Circle) 
import turtle

turtle.bgcolor("#ffffff")
turtle.color("purple")
turtle.width(4)

turtle.penup()
turtle.goto(0, -50)
turtle.pendown()

turtle.circle(80)
print("دایره کشیده شد! 🟢")

۴. استفاده از شرط (If / Else)
